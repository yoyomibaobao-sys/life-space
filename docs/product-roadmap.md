# LifeSpace 产品路线图

> 本文只记录已确认的产品方向与阶段优先级，不作为当前上线阻断清单。
> 后续讨论中形成的新想法，如确认纳入产品方向，就继续在这里和对应专题计划中完善；尚未确认的想法不作为开发任务。

## 当前阶段：基础上线与稳定

优先完成并稳定以下基础能力：

- 正式域名与注册确认链路
- 正式 SMTP、邮箱确认与找回密码
- Turnstile / CAPTCHA
- 云端试用领取与会员状态展示
- 本地 / 离线核心闭环
- Android 基础体验与 Google Play 上架准备
- 中国大陆无 VPN 的关键链路可用性与加载体验

## 下一阶段：重点新增能力

### 1. 地区地图

目标：把“发现”从内容流扩展为按地区发现真实种植经验，逐步形成全球地区种植知识网络。

详见：`docs/plans/regional-map.md`

### 2. 商社会员

目标：为小种植户、家庭农场、苗圃、工作室及小团体提供长期经营主页、稳定商品目录和多人协作能力，与个人集市发布区分。

详见：`docs/plans/merchant-membership.md`

## 后续阶段方向

以下方向已讨论，但不进入当前开发：

- 相似气候地区推荐
- 地区化实操指引
- 地区 × 植物 × 月份的经验聚合
- 资讯订阅体系（与商社会员分开）
- 更完整的全球地区种植数据能力

## 维护规则

- 已确认的产品方向：写入本路线图或对应专题计划。
- 新想法：先讨论，确认后再纳入。
- 真正进入开发时：再拆成 GitHub Issue / PR 任务。
- 当前上线清单继续独立维护，不把未来功能混入上线阻断项。
