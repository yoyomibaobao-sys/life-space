# 站内举报与反馈接线

用户此前确认普通举报尽量站内闭环。本批复用已经部署的 `20260910220927_add_support_submission_workflow.sql`，不修改生产表或用户数据。

- `/feedback`：登录后提交结构化反馈、查看本人记录、按需补充一次说明；保留产品理念文案。邮件入口用于需私下核实的账号、付款和数据安全事项。
- `/report`：从项目、记录、经验卡、集市及用户空间带入举报对象，也可粘贴本站内容链接。展示重复举报状态与处理结果。
- `/admin/support`：管理员查看举报/反馈队列，请求一次补充、登记结果，同一内容的待处理举报一并结案并产生站内通知。内部备注仅管理员可见。登记结果不等于自动隐藏/删除内容。
- 通知保留数据库生成的本人处理记录链接；中英文分类名称补齐。用户信息页增加管理员处理入口。
- 链接只允许本站路径，并剔除无关查询、凭据与片段。账号切换卸载上一账号的表单与历史；请求失败保留输入。

验证：TypeScript、修改范围 ESLint、举报 URL 输入测试、PGlite 权限/隔离/去重/补充/批量通知测试以及 Cloudflare 构建。生产发布状态以 PR 和部署记录为准。

本批不含仍在单独处理的离线界面、离线指引概要和原云项目补传草稿。
