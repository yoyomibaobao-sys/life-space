# 离线指引基础概要与 Android rc7

本批补齐 Android 断网时的指引详情，沿用注册非云会员的读取边界，不修改 Supabase 表、RLS、函数或生产数据。

## 行为

- 离线指引卡先打开详情，再由用户选择是否按该指引新建本地项目。
- 设备保留有效登录账号上下文时，可查看基础概要，以及植物的光照、栽培场景、室内适配和搭架参考；公共指引最多缓存前三项基础参数。
- 未登录访客仍只能浏览名称与分类，详情页提示联网登录／注册。指引列表也不会向访客展示已缓存的概要描述。
- 在线登录后访问指引库会刷新中英文基础缓存。缓存清洗只接受平台内置、植物物种和公共指引来源；私有项目名称、完整实操、周期、注意事项、经验卡和关联项目不写入缓存。
- 尚无精确缓存时只显示明确标注的通用核对框架，不生成具体物种养护结论。

## 升级

- Android 身份仍为 `com.youshi.cultivation`，正式签名流程不变。
- 默认版本提升为 `1.0.4-rc7` / `versionCode 11`，保证已安装 rc6 的设备可以通过官方更新器覆盖安装。
- IndexedDB 名称与版本不变；本批仅扩展原有 `lifespace:guide-directory:v1` 的兼容性 localStorage 内容，不迁移、不删除现有本地项目、记录或照片。

## 验证

- 离线目录运行测试覆盖来源白名单、字段上限、完整内容排除、窄植物参数、中英文概要、名称刷新合并和损坏缓存回退。
- Android 静态合同覆盖访客门槛、离线详情、新建项目入口、版本号和单文件资源。
- TypeScript、修改范围 ESLint、Android 离线壳生成及 Cloudflare `vinext` 生产构建通过。

原云项目补传草稿不在本批范围内。
