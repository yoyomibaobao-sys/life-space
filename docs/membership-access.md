# LifeSpace 首发用户状态与权限

本文件记录当前已确认的首发权限模型。用户可见状态只分为游客、本地免费用户和云空间会员；旧试用与内部方案仅用于过渡或兼容。

## 权限矩阵

| 权限 | 游客（未注册） | 本地免费用户 | 云空间会员 |
| --- | --- | --- | --- |
| 浏览公开发现、公开记录和集市 | ✓ | ✓ | ✓ |
| 查看已有互动数量与内容 | ✓ | ✓ | ✓ |
| 本机离线项目、记录和图片 | ✓ | ✓ | ✓ |
| 植物目录、名称和分类 | ✓ | ✓ | ✓ |
| 植物指引基础概要 | — | ✓ | ✓ |
| 少量核心静态参数 | — | ✓ | ✓ |
| 完整参数、生长周期和完整养护指引 | — | — | ✓ |
| 指引中的相关种植记录 | — | — | ✓ |
| 未来：作者主动公开的单张经验卡（直接链接／二维码） | ✓ | ✓ | ✓ |
| 未来：创建经验卡、经验卡库、搜索、筛选和比较 | — | — | ✓ |
| 评论、回复、点赞、鲜花和关注 | — | — | ✓ |
| 集市咨询和联系发布者 | — | ✓ | ✓ |
| 云端私密保存、同步和备份 | — | — | ✓ |
| 公开发布、求助和集市发布 | — | — | ✓ |
| 集市同时“发布中” | 0 | 0 | 最多 30 条 |
| 云空间容量 | 0 | 0 | 1GB |

“本地免费用户不能查看种植记录”特指植物指引中汇聚的相关公开种植记录，不影响用户在当前设备免费记录自己的本地项目。

本地免费用户的核心静态参数目前只包括日照评分、是否需要搭架，以及盆栽、室内、阳台适配评分。地区和季节适配、精确温湿度与土壤阈值、完整养护方法、经验聚合和多案例比较仍属于云空间能力。应通过窄化接口返回这些字段，不能向本地免费用户开放 `plant_parameters` 整行读取。

集市咨询是注册用户与发布者之间的交易联系，不属于社区互动。注册后的本地免费用户可以在仍处于“发布中”的集市内容下咨询；社区评论、回复、点赞、鲜花和关注仍只开放给有效云空间会员。

## 记录照片

- 单条记录累计照片数量不设产品上限，本地总量只受设备空间限制，云端总量受云空间容量限制。
- 每次选择、添加或上传最多 10 张，可以分多次添加到同一条记录。
- 所选照片跨多个日期时，用户可以按照片日期拆分，同一天的照片生成同一条记录；也可以选择不拆分，合并后的记录日期采用所选照片中的最新日期。
- 无论是否拆分，都应保留每张照片自身的原始拍摄时间，供以后生成生长线和短视频时按真实时间排序。

## 经验卡与外部传播（后续功能）

- 只有有效云空间会员可以创建经验卡和生成 15 秒／30 秒竖屏 MP4。
- 视频可由用户选定照片，生成照片时间线、节点字幕和结尾二维码，同时提供可复制的短链接。
- 作者主动设为公开的单张经验卡，可由游客通过直接链接或二维码完整查看，以承接外部分享流量。
- 经验卡库、站内搜索、筛选、聚合同类经验和多案例比较仍只对有效云空间会员开放。
- 上传云端不等于公开；私密照片不得自动进入经验卡或视频。生成和分享必须由用户主动确认。
- 视频渲染的成本和合理用量以后按真实使用情况确定，当前不承诺无限生成。

## 专业卖家与试用／试种（后续功能）

- 专业卖家是附加商业身份，不替代游客／本地免费／云空间这条账户等级轴；专业卖家包含云空间权益。
- 普通云会员发布的是个人供需信息；每条最长发布 30 天，到期后可一键续期并重新校验会员状态和发布额度。
- 专业卖家以后拥有卖家详情页、长期产品目录、分类与批量管理、供应状态和专门的管理界面，而不是简单获得无限期普通帖子。
- 只有专业卖家可以发布试用／试种招募；招募必须包含名额、报名截止日期、任务周期、地区和条件、记录要求、回报与结果提交方式。
- 只有报名时仍有效的云空间会员可以申请试用／试种。普通本地免费用户可以咨询，但不能报名。
- 发布人可根据报名者主动公开、或在本次报名中明确授权展示的种植经验选定约定名额；不得读取或披露报名者的私密项目、私密记录、联系方式或未授权数据。
- 报名页面应展示与招募相关的经验证据和用户主动填写的信息，不应给发布人开放报名者整个云空间。

## 价格与续费

- 云空间首发价：¥64/年或 US$8/year。
- 当前不自动续费。
- 当前不提供集市加量包。
- 不承诺永久价格；未来如调整，只在后续续费时明确告知。

## 注册、试用与到期

- 新注册账号成为本地免费用户，不自动获得云空间试用。
- 现有 4 个试用账号保留原到期日、原容量和原集市额度，直到各自到期。
- 到期后已有云端内容不会删除；用户仍可查看、导出和删除，但不能新增云端内容、互动或重新发布集市。
- 已结束的集市条目不占 30 条额度；重新发布时必须重新校验额度。

## 内部兼容

- `admin` 是内部管理角色，不是对外会员种类。
- `large` 和 `seller` 暂不公开展示或销售，只保留现有数据库兼容结构。
- `market_post_quota_addons` 暂作兼容预留，不计入当前额度。
