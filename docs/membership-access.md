# LifeSpace 首发用户状态与权限

本文件记录已确认的权限目标；实现与生产状态仍须逐项验收。正式账号邮箱确认后可主动领取一次30MB、90天体验，自然到期或主动提前结束后进入30天只读处理期；有效云体验与有效 Plus 拥有相应云写入权益。历史内部账号及旧试用保留兼容状态。“云空间”表示云端存储与同步能力；独立本地空间由 SAF 目录的 localSpaceId 决定，与云账号解耦。

## 权限矩阵

| 权限 | 游客 | 注册免费 | 有效云体验 | 有效 Plus |
| --- | --- | --- | --- | --- |
| 浏览公开发现、记录和集市；查看公开互动 | ✓ | ✓ | ✓ | ✓ |
| 当前已连接本地目录的项目、记录和图片 | ✓ | ✓ | ✓ | ✓ |
| 植物基础概要与少量核心静态参数 | ✓ | ✓ | ✓ | ✓ |
| 已提供的完整参数、生长周期与养护指引 | — | — | ✓ | ✓ |
| 指引汇聚的相关种植记录、经验卡库与聚合比较 | — | — | ✓ | ✓ |
| 作者主动公开的单张经验卡直接链接 | ✓ | ✓ | ✓ | ✓ |
| 创建经验卡及社区评论、回复、点赞、关注 | — | — | ✓ | ✓ |
| 集市咨询联系发布者 | — | ✓ | ✓ | ✓ |
| 新增云端私密内容、同步、公开发布及求助 | — | — | ✓ | ✓ |
| 同时“发布中”的集市内容 | 0 | 0 | 最多 3 条 | 最多 30 条 |
| 云空间容量 | 0 | 0 | 30MB | 1GB |

云权益结束后的只读、导出和逐项目本机复制另按下文处理；生产权限须由服务端校验，不能只隐藏按钮。

“注册免费用户不能查看指引中的相关种植记录”特指植物指引汇聚内容，不影响游客或注册用户在当前设备免费记录自己的本地项目。

游客与注册免费用户的核心静态参数目前只包括日照评分、是否需要搭架，以及盆栽、室内、阳台适配评分。地区和季节适配、精确温湿度与土壤阈值、完整养护方法、经验聚合和多案例比较仍属于有效云体验与 Plus 权益。应通过窄化接口返回这些字段，不能向免费用户开放 `plant_parameters` 整行读取。

集市咨询是注册用户与发布者之间的交易联系，不属于社区互动。注册后的本地用户可以在仍处于“发布中”的集市内容下咨询；社区评论、回复、点赞、有用反馈和关注仍只开放给有效云会员。

## 记录照片

- 单条记录累计照片数量不设产品上限，本地总量只受设备空间限制，云端总量受云空间容量限制。
- 每次选择、添加或上传最多 10 张，可以分多次添加到同一条记录。
- 所选照片跨多个日期时，用户可以按照片日期拆分，同一天的照片生成同一条记录；也可以选择不拆分，合并后的记录日期采用所选照片中的最新日期。
- 无论是否拆分，都应保留每张照片自身的原始拍摄时间，供以后生成生长线和短视频时按真实时间排序。

## 经验卡与外部传播（后续功能）

- 只有有效云会员可以创建经验卡和生成 15 秒／30 秒竖屏 MP4。
- 视频可由用户选定照片，生成照片时间线、节点字幕和结尾二维码，同时提供可复制的短链接。
- 作者主动设为公开的单张经验卡，可由游客通过直接链接或二维码完整查看，以承接外部分享流量。
- 经验卡库、站内搜索、筛选、聚合同类经验和多案例比较仍只对有效云会员开放。
- 上传云端不等于公开；私密照片不得自动进入经验卡或视频。生成和分享必须由用户主动确认。
- 视频渲染的成本和合理用量以后按真实使用情况确定，当前不承诺无限生成。

## 商社会员与试用／试种（后续功能）

- 商社会员面向个人经营者、苗圃、农场、工作室、小型商家和协作团队，包含主账号的云会员基础权益；个人也可以开通。
- 云会员发布的是个人供需信息；每条最长发布 30 天，到期后可一键续期并重新校验会员状态和发布额度。
- 商社会员以后拥有商家主页、长期产品目录、分类与批量管理、供应状态、试用／试种招募、站内咨询和商社项目共同管理能力。
- 商社会员采用“商社空间＋成员账号”：每位成员使用自己的个人账号登录，由所有者邀请并授权，不允许多人共用同一登录账号和密码。
- 商家主页、产品目录、专业发布、招募、咨询和主动转入商社的项目归商社空间所有；成员退出后内容仍保留，重要操作记录实际操作人。
- 首版成员角色可先采用“所有者／管理员／成员”，并逐项控制商家资料、产品、招募、咨询、数据与成员管理权限。
- 受邀成员获得的是商社管理权限，不自动获得个人云会员权益；需要个人云空间或个人公开发布时仍需单独开通云会员。
- 商社会员可以发布试用／试种招募；招募必须包含名额、报名截止日期、任务周期、地区和条件、记录要求、回报与结果提交方式。
- 只有报名时仍有效的云会员可以申请试用／试种。本地用户可以咨询，但不能报名。
- 发布人可根据报名者主动公开、或在本次报名中明确授权展示的种植经验选定约定名额；不得读取或披露报名者的私密项目、私密记录、联系方式或未授权数据。
- 报名页面应展示与招募相关的经验证据和用户主动填写的信息，不应给发布人开放报名者整个云空间。

## 价格与续费

- 云会员首发价：¥64/年或 US$8/year，包含 1GB 云空间。
- 商社会员尚未开放，价格、默认成员名额与增购规则待开发前确认。
- 当前不自动续费。
- 当前不提供集市加量包。

## 付款订单、PayPal 自动开通与支付宝人工确认

- 当前只提供一次性年费订单，不自动续费。人民币订单固定为支付宝 ¥64，美元订单固定为 PayPal US$8；暂不提供微信支付入口。
- 登录用户必须先由服务端创建固定金额的 LifeSpace 订单，前端不能自行指定方案、金额、币种或付款方式。
- PayPal 由服务端创建一次性 Orders v2 订单：`custom_id` 固定为本地付款 UUID，`invoice_id` 固定为本地订单号。服务端必须先把 PayPal 订单号唯一绑定到本地订单，才向浏览器返回 PayPal 批准地址。
- PayPal 返回页和通过签名验证的 Webhook 都必须重新读取 PayPal 的规范订单。只有本地已绑定的 PayPal 订单可以被 Webhook 捕获；确认前必须同时匹配唯一购买单元、唯一已完成捕获、US$8、USD、本地付款 UUID、本地订单号、PayPal 订单号和捕获号。成功后在同一数据库事务中开通或顺延 12 个月、更新 1GB 容量和 30 条集市额度。同一订单或捕获重复送达时只返回既有结果，不重复延长。
- 支付宝暂不具备自动支付接口时，订单页直接显示已配置的支付宝经营／商家收款码和收款方名称；用户付款后上传凭证，由管理员在真实收款账户核对后确认。PayPal 不上传付款凭证，也不进入新的人工确认队列。
- 支付宝收款码或收款方未配置时，支付宝订单入口必须明确禁用，不能退回邮件获取方式；收款码及收款方属于公开展示信息，不得把支付宝密码、私钥或其他凭据放入前端环境变量。
- 支付宝付款凭证保存在私有 `payment-proofs` Storage bucket。每个订单只保留一个可覆盖的凭证对象，只有订单本人和管理员可以读取，不进入公开资料、发现页或导出包。
- 支付宝订单通常依次为 `pending_payment`、`submitted`、`needs_update`、`confirmed`；PayPal 从 `pending_payment` 在服务端确认后直接进入 `confirmed`。退款和取消继续使用 `refunded`、`canceled`，未付款超时使用 `expired`。
- 管理员账号在“我”页看到支付宝待确认数量提醒，并从会员管理页打开私有凭证。凭证不清楚时只能要求用户补充；确认前必须核对账号、订单号、金额和付款状态。历史人工 PayPal 订单可继续按原记录处理，但新 PayPal 订单不得要求截图。
- 普通登录用户只能查询自己的订单，不能直接插入、修改或删除付款表；匿名用户不能读取订单、付款凭证或调用订单 RPC。

## 退款申请与原路退款

- 用户从“用户信息 → 订单查询 → 申请退款”选择自己的已确认订单；系统以申请成功提交时间锁定退款档位和金额。
- 付款确认后 7 个自然日内退还实付金额的 100%；第 8 个自然日至第 180 个自然日内退还 50%；超过 180 个自然日原则上不受理个人原因退款。
- 尚未开始服务期的续费订单在付款确认后 180 日内全额退款。重复扣款、未开通或未交付、平台造成的严重持续服务故障和法定情形单独核实，不受个人原因比例限制。
- 管理员必须使用两阶段流程：先审核并锁定金额，再到原支付宝或 PayPal 交易执行真实退款；只有退款成功并登记外部退款参考号后，才能确认完成并回退会员权益。
- 旧的“直接标记已退款”入口禁用。数据库 RPC 同样拒绝绕过退款申请、外部退款参考号和权益回滚而直接修改为 `refunded`。
- 同一付款订单只能建立一笔退款申请。存在未完成退款时不确认新的会员付款，也不允许注销账号，避免服务期限、审计记录和退款责任脱节。
- 完整公开规则位于 `/legal/refunds`，隐私说明、服务条款和运营联系分别位于 `/legal/privacy`、`/legal/terms`、`/legal/contact`。

上线顺序必须先执行付款订单 migration 和数据库目录测试，再配置部署端的 PayPal／Supabase 服务端密钥、完成 PayPal Sandbox 全流程，最后发布调用新 RPC 的网页／App 代码。不得先发布前端后补数据库，也不得在 Sandbox 未通过时切换 PayPal Live。

## 管理员中心与销号

- 管理员中心分为概览、访问统计、会员注册、付款确认、网站容量和销号管理。统计数据统一由管理员专用 RPC 汇总，普通用户和匿名访问者不能读取原始统计表或销号审计表。
- 页面浏览只记录归一化路由模板、时间、平台和匿名访客标识。动态用户／项目 ID 会替换为 `[id]`，未知路径统一记为 `/not-found`；不记录查询字符串、搜索词、页面内容、精确位置、邮箱或设备指纹。
- APP 下载次数以实际 Android 下载接口被请求为准。浏览统计从包含 `page_view` 的版本上线后开始积累，不补算历史数据。
- “停用会员”只停止会员权益，保留账号、用户资料和付款记录，可由管理员以后重新开通；“永久注销账号”会删除账号、资料、项目、记录和文件，两者不得混用。
- 管理员永久注销普通账号时必须选择明确目标、输入完整账号编号并再次勾选不可恢复确认。管理员不能在此页面注销自己，也不能直接注销其他管理员账号。
- 每次自行注销或管理员销号都必须先建立服务端审计记录；只有审计创建成功才开始删除。审计仅保留账号编号、目标 UUID、发起方式、状态、时间、清理文件数和通用错误码，不保留邮箱或用户内容。
- 删除中途失败时，审计状态标记为失败并进入人工复核；界面不能把部分删除误报为已完成。

### 公开收款上线前检查

- 支付宝必须使用经营／商家收款码；收款方名称应与用户扫码后看到的名称一致。当前默认使用项目内的固定 ¥64 经营收款海报 `/payments/alipay-cloud-membership-64.jpg`，收款方显示为 `有时空间`，用途标明为“开通云会员”；`NEXT_PUBLIC_ALIPAY_PAYMENT_QR_URL` 和 `NEXT_PUBLIC_ALIPAY_PAYEE_NAME` 仅作为以后更换收款资料时的可选覆盖值。覆盖地址无效时支付宝入口保持禁用。
- PayPal 必须使用获准收款的商家账户和 REST App。`PAYPAL_CLIENT_SECRET`、`PAYPAL_WEBHOOK_ID`、`SUPABASE_SERVICE_ROLE_KEY` 只能作为部署端密钥；`PAYPAL_SITE_ORIGIN` 必须是当前环境的精确 HTTPS Origin。生产回调和 Webhook 使用 `https://life-space.uk`，Sandbox 测试使用隔离的测试环境地址。
- 先用 PayPal Sandbox 覆盖：正常返回、付款后关闭页面由 Webhook 补开通、同一回调和 Webhook 重放、错误金额／币种／订单号拒绝、无本地绑定的有效 Webhook 不触发捕获。确认一年期限与 1GB 容量只变化一次后，才切换 `PAYPAL_ENV=live` 并重建 Live Webhook。
- 分别完成一笔支付宝和一笔 PayPal 的真实全流程测试。支付宝需要上传凭证并由管理员在实际收款账户核对；PayPal 需要核对服务器记录的订单号、捕获号、金额和完成状态，并确认无需人工操作即开通一年。管理员不能只看用户页面或截图。
- 重复确认／回调同一订单不得重复延长；退款既要在实际支付平台完成，也要在后台两阶段流程中登记，网站后台批准状态不能代替真实退款。
- 已提供公开的隐私说明、服务条款、退款规则与运营联系页面。面向不特定公众推广前，仍需核对实际运营主体名称、登记／许可、公示项目、服务地区和收款账户资格，不得用页面文案代替依法需要的主体资质。

## 注册、试用与到期

- 正式账号编号采用 `LSa + 四位注册年份 + 三位流水码`，例如 `LSa2026001`；旧 `LSa-2026-0001` 等格式继续兼容读取，不重建账号或变更身份。
- `a` 是注册时账户类别；编号永久不变，总序号跨年份和未来类别连续累加，删除账号后不回收。
- 现有账号标记为内部测试账号，不获得正式编号，不占正式排名；它们保留原有容量、到期日和集市额度，不参与新的注册用户体验领取。
- 每个正式注册账号在邮箱确认后可主动领取一次30MB云端体验；从领取时开始计算90天，不能重复领取。
- “云空间”入口不因游客、未领取体验、试用到期、Plus 到期或本地显示开关而隐藏；只有实际云项目可访问时才与开启的本地一起显示「全部」。无有效云写入权益的云空间引导，以及本地转云受限时，明确区分“开通90天云端试用”和“升级Plus会员”；游客先登录／注册，已使用或不符合试用资格的账号只提供 Plus，邮箱未验证先提示确认，读取失败须重试。两者各走已有试用／付费流程，开通后不会自动转云或公开本地内容。
- 注册、领取体验都不会自动上传或公开本地内容。用户直接新建的云端项目和记录默认公开；云端项目切换公开或私密时，其现有记录及今后新增记录统一跟随。把本地项目转到云端时，由用户一次选择“公开”或“仅自己可见”，项目与全部记录统一采用该选择。
- 安全预算按平台实际Storage占用加上当前有效体验尚未使用的部分计算，避免已上传照片重复占用预算；预计下一份30MB会越过700MB安全线时暂停新领取，但注册始终开放。
- 体验容量用完后仍可继续本地记录。90天自然到期或用户主动提前结束时，立即停止云端新增、编辑、上传、互动和发布，进入只读；提前结束须服务端校验并原子更新结束与处理期限，重复请求不得延长，不终止有效 Plus。
- 自结束时开始30天处理期；用户可开通 Plus、备份导出，或在本人云项目菜单逐个“保存到本机（复制）”。处理期结束后立即停止访问原体验云资料，但不自动物理删除；管理员按处理期结束后的五个时间区间多选并手动发起分批清理。
- 清理前成功升级 Plus 可恢复尚未实际删除的云项目、记录和照片，清理后不承诺恢复。管理员清理不删除账号、个人资料、付款记录或本地数据；从未付费的正式体验账号才是候选，已确认且未撤销的付费历史永久排除。
- 用户可见提示写明云端体验结束后只读和处理期限，引导逐项目保存到本机或备份；不称“转回本地”，不以“删除云端数据”提示，也不暗示系统自动下载。
- “我的空间”标题下，有效体验最后7天显示一条备份提醒，结束后的处理期显示剩余天数和备份入口；时间以服务端为准。处理期结束前7天额外发送一次站内关键提醒，可在同一节点发送一封 SMTP 邮件；旧的30天、到期、清理完成等多轮通知不得继续发送，邮件失败不阻断状态更新。
- 曾经至少有一笔确认成功且未被撤销的付费会员记录，账号永久退出免费体验手动清理候选。会员到期未续费后，未由用户主动删除的云端内容长期保留并只读，可随时、多次保存到本机；允许查看、导出、删除和公开转私密；禁止新增、编辑、上传、互动、重新发布以及私密转公开。续费后恢复云端写入和同步。
- “启用本地空间”只是本机显示偏好，关闭不删除 SAF 数据。正式取消“云端转本地／转回本地”迁移和批量“全部保存到本地”。有效云体验或 Plus 时不开放复制；结束服务后允许逐项目复制，云端原件始终不变。
- 同一来源项目若已有完整未修改的本机副本，可打开而不重复创建；中断可重试，本机已编辑内容绝不静默覆盖。复制完整校验分类、分期、记录、照片、SAF 提交与 pending 归属，不将轻缓存冒充完整副本。备份与导出独立保留。
- 有效云体验或 Plus 才能主动把独立本地项目上传为新的云项目。即使来自某云项目副本，也不覆盖原件；仅新项目名称冲突时自动添加编号，本地名称不变。相同上传任务失败重试必须复用已持久保存的目标 ID、令牌和目标账号，避免重复云项目与记录／照片。
- 现有 4 个内部试用账号保留原到期日、原容量和原集市额度，直到各自到期。
- 现有内部试用账号不参加正式账号的领取与手动清理规则，新迁移不得重写它们的当前容量、日期或集市额度。
- 已结束的集市条目不占 30 条额度；重新发布时必须重新校验额度。

### 逐项目保存到本机与用户可访问目录

- 用户只在本人云项目现有菜单逐个“保存到本机”；Plus 到期后云端原件长期只读，云体验处理期受30天限制。服务器资格读取失败时不放行复制。
- SAF 已验证提交是独立本地用户数据来源；App 私有 IndexedDB 是运行镜像。旧已验证 SAF 目录与身份保留，新目录默认目标为公共 `Documents/LifeSpace`；不得覆盖或静默迁移。
- 逐项目复制和外部备份须分别处理完整性、幂等、空间不足、授权失效、中断重试与重复导入。失败不得删除、隐藏或回收云项目，也不得损坏已有本机资料。
